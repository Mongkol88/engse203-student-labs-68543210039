## ทดสอบว่าข้อมูลอยู่ถาวร (CP08)

| ขั้น | ทำอะไร | ผลที่เห็น |
|---|---|---|
| 1 | POST เพิ่มคำร้องใหม่ | ได้ 201 พร้อม object คำร้องใหม่ที่มี id เช่น `REQ-...` และ status เป็น `pending` |
| 2 | GET ดูรายการ — เห็นคำร้องใหม่ไหม | เห็น คำร้องใหม่อยู่ในรายการพร้อมข้อมูลครบถ้วน |
| 3 | Ctrl+C ปิดเซิร์ฟเวอร์ แล้วเปิดใหม่ | เซิร์ฟเวอร์เริ่มทำงานใหม่และโหลดข้อมูลจาก `data/requests.json` ได้สำเร็จ |
| 4 | GET ดูรายการอีกครั้ง — คำร้องยังอยู่ไหม | ยังอยู่ คำร้องที่เพิ่มและแก้ไขก่อนปิดเซิร์ฟเวอร์ยังคงอยู่ครบถ้วน |
