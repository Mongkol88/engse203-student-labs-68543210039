# B1 · บันทึกการแก้บั๊ก (กรอกให้ครบทั้ง 6 จุด)

> แต่ละบั๊กให้เขียน 4 อย่าง: ไฟล์ · บรรทัด · สาเหตุ (ทำไมทำงานผิด) · แก้อย่างไร
> เขียนด้วยคำของตัวเอง — จุดนี้จะถูกถามใน oral

## บั๊กที่ 1 — อาการ: Console เตือนสีเหลืองเรื่องรายการ
- ไฟล์/บรรทัด: RequestList / 8-9
- สาเหตุ: ใน RequestCard ไม่มี key 
- แก้อย่างไร: ใส่ key={request.id} ใน RequestCard

## บั๊กที่ 2 — อาการ: ตัวเลข "รอดำเนินการ" ในแผงสรุปไม่ตรงกับที่เห็น
- ไฟล์/บรรทัด: DashboardPage / 54-55
- สาเหตุ: บรรทัด 54-55 เกิดจากการตั้ง request.status !== statusFilter 
- แก้อย่างไร: บรรทัด 54-55 เเก้โโดยการตั้งการเปรียบเทียบจาก request.status !== statusFilter เป็น request.status === statusFilter);

## บั๊กที่ 3 — อาการ: กดตัวกรอง "รอดำเนินการ" แล้วได้รายการที่ไม่ใช่
- ไฟล์/บรรทัด: DashboardPage / 47 
- สาเหตุ: บรรทัด 47 filler ถูกตั้งเป็น completed ซึ่งซ้ำกับบรรทัด 49 ไปเเล้ว
- แก้อย่างไร: บรรทัด 47 เเก้โดยการเปลี่ยนจาก completed เป็น pending

## บั๊กที่ 4 — อาการ: เปลี่ยน URL จาก REQ-001 เป็น REQ-002 แล้วข้อมูลไม่เปลี่ยน
- ไฟล์/บรรทัด: RequestDetailPage / 16-31
- สาเหตุ: เกิดจากการใส่ if ingore ใน .then เเละ .catch ถ้าเกิด ignore เป็น true ก็จะถูก return กลับทันทีทำให้ไม่ reload ตอนเปลี่ยน url  
- แก้อย่างไร: ลบโค้ดที่เกี่ยวกับ ignore ให้หมดหรือเงื่อนไขเเละเพิ่ม   setErrorMessage(''); ด้วย

## บั๊กที่ 5 — อาการ: กด "ลบ" แล้วรายการยังอยู่ ต้องรีเฟรชถึงหาย
- ไฟล์/บรรทัด: DashboardPage / 62-69 
- สาเหตุ: เกิดจากการใส่  setRequests(requests); เป็น (requests) ทำให้มันถูกกดลบเเล้วไม่หายทันที
- แก้อย่างไร: ทำให้การเปลี่ยนจาก (requests) เป็น (nextRequests)

## บั๊กที่ 6 — อาการ: กด "Reset Demo Data" แล้วหน้าพัง/ว่างเปล่า
- ไฟล์/บรรทัด: DashboardPage / 75
- สาเหตุ: เกิดจากการ setRequests() ใส่ใน para เป็น resetRequests() เลยทำให้เมื่อกด Reset data เลยพัง
- แก้อย่างไร: เพิ่ม const seedRequests = await resetRequests(); เเละ เปลี่ยน setRequests() ใน para เป็น seedRequests
