## 3 คำถามที่ต้องตอบ

### 1. ทำไมโปรเจกต์นี้เลือก SQLite แทน MongoDB

**ตอบ** โครงสร้างข้อมูลชัดเจน : ข้อมูลคำร้อง มีฟิลด์และเงื่อนไขที่แน่นอนทุกแถว และมีความสัมพันธ์กับตาราง `users` จึงเหมาะกับฐานข้อมูลแบบ SQL มากกว่าฐานข้อมูล MongoDB พร้อมทั้ง MongoDB ใช้สำหรับข้อมูลระบบ Big data ส่วน SQLite เบาเเละทำงานได้เร็วกว่า

### 2. ถ้าวันหนึ่งต้องเปลี่ยนไป MongoDB จะกระทบชั้นไหนบ้าง

**ตอบ** กระทบ Service `api/src/services/` เพราะ ต้องเปลี่ยนโค้ดจากคำสั่ง sql ของ SQLite ไปเป็นคำสั่งของ MongoDB และเปลี่ยนการตั้งค่าใน `config.js` ตรง `dbFile` ให้เป็น path ใหม่

### 3. async จำเป็นเมื่อไร ไม่จำเป็นเมื่อไร

**ตอบ** จำเป็นเมื่อต้องมีการเรียกใช้ข้อมูลหรือ service ด้านนอก เช่น api, database ถ้าเกิดไม่มี async จะทำให้ไม่ได้รับข้อมูลหรือข้อมูลอาจได้รับไม่ครบเพราะ เน็ตช้า หรือ connection timeout
